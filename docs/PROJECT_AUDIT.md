# 部署前项目检查

检查时间：2026-10-29。检查对象为当前工作区，不只使用最近一次提交。

## 原架构

- Rails 7.2（Gemfile 约束）、Ruby、ERB 服务端模板。
- Bootstrap 5.3、Sass/Sprockets；课程 UI 位于 `_course.scss`、`_course_home.scss`、`_course_marketplace.scss`、`_course_post.scss`。
- PostgreSQL / pg，Devise 认证，ActiveAdmin 管理；另有 Sidekiq / Redis 后台任务、Active Storage / S3 相关能力。
- 路由与模板读取社区、用户、服务、会员和时间账本模型，完整应用不能作为静态文件直接运行在 Cloudflare Pages。
- 当前 V1 使用系统中文字体和内联 SVG，不依赖外部中文字体；课程插画位于 app/assets/images。

## 页面与后端依赖

| 页面或能力 | 可静态部署的部分 | 原 Rails / PostgreSQL 依赖 |
| --- | --- | --- |
| 首页 | 插画、文案、导航、时间银行规则、参与步骤 | 登录态、成员摘要、动态数量与余额 |
| 互助广场 | 分类、卡片和展示布局；可对模拟数组搜索筛选 | 实时供需查询、权限、分页查询和发布存储 |

| 居民资料 / 时间银行 | 虚构居民、固定账本与计算余额 | 真实成员、账户、转账记录与权限校验 |
